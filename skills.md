# Claude Skills - Research Project

## Skill 1: Meeting Summary Writer
Description: Takes meeting notes and creates a clean summary
Input: Raw messy meeting notes
Output: Organized summary with action items
Instructions:
- Extract key decisions made
- List action items with owners
- Highlight deadlines
- Keep it under 200 words

## Skill 2: Code Explainer
Description: Explains code in simple English
Input: Any code snippet
Output: Line-by-line explanation a beginner can understand
